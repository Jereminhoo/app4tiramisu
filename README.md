# 🍮 App4Tiramisu

## 📖 Le Contexte
Ce projet est né d'une aventure familiale. Mon frère, alias **"Le Préparateur"**, réalise des tiramisus qui ont rapidement conquis notre entourage. Après un premier succès sur Instagram et des livraisons gérées à la main, nous avons décidé de passer au niveau supérieur.

L'objectif de cette application est de professionnaliser la prise de commande et de centraliser la gestion des stocks pour relancer l'activité de manière plus sophistiquée et automatisée.

## 🚀 Vision Technique
Le projet est conçu avec une architecture moderne pour garantir performance et scalabilité :
* **Back-end :** Node.js avec le framework Express.
* **Front-end :** React pour une expérience utilisateur fluide.
* **Hébergement :** Serveur domestique sur Raspberry Pi 4.
* **Base de données :** MariaDB pour la gestion des commandes et du catalogue.

## 🛠️ Installation

### Prérequis
* Node.js (v20+)
* NPM

### Lancement local
1. Cloner le projet :
```bash
   git clone [https://github.com/Jereminhoo/app4tiramisu.git](https://github.com/Jereminhoo/app4tiramisu.git)
   ```
Installer les dépendances :
```bash
   npm install
   ```
Lancer le serveur de test :
```bash
   node index.js
   ```
